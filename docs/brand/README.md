# OMERTÀ — logo

A single rose, hanging by its stem from one ring, inside a coin. Flat 2D:
three inks of one rose (deep, mid, bright magenta), a green stem with two
thorns and one leaf, one drop. The ring is the token; the hairline reticle
at the four points is the sealed file. Omertà is the code of silence — the
rose is what you leave, not what you say.
